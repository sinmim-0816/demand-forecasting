# Crop Recommendation

The current component is a rule-based market-opportunity ranking engine. It is not a third AI forecasting model. It consumes future demand and price forecasts generated by the two trained models.

Commands are documented in [RUN_GUIDE.md](RUN_GUIDE.md). Folder placement is documented in [ARCHITECTURE.md](ARCHITECTURE.md).

## Current scope

```text
Farmer and farm input
        +
Active planting records
        +
Future demand predictions
        +
Future procurement-price predictions
        |
        v
Validation and remaining-land calculation
        |
        v
Demand and price normalization
        |
        v
50% demand + 50% price opportunity score
        |
        v
Ranked crop/month recommendations
```

The current engine ranks market opportunity. It does not yet claim complete planting suitability.

## Source files

| File | Responsibility |
|---|---|
| `src/crop_recommendation/config.py` | Input/output paths and neutral 50/50 weights. |
| `src/crop_recommendation/validators.py` | Farmer input, planting-record, date, location, and land validation. |
| `src/crop_recommendation/scoring.py` | Min-max normalization, weighted scoring, and ranking. |
| `src/crop_recommendation/recommend_crops.py` | Loads forecasts, builds candidates, calls validation/scoring, and saves output. |

## Temporary inputs before API integration

```text
data/recommendation/sample_farmer_input.json
data/recommendation/sample_active_plantings.json
data/recommendation/crop_defaults.csv
```

The sample farmer input contains:

- Farmer and farm identifiers
- Location
- Total and requested land area
- Planting month
- Planning horizon in months

Active planting records let the engine calculate land already occupied during the requested planting month.

## Forecast inputs

Configured real model outputs:

```text
artifacts/demand/predictions/xgboost_tuned_future_forecast_h1_h12.csv
artifacts/price/predictions/xgboost_future_price_forecast_h1_h12.csv
```

Demand and price rows must match on crop, location, and target month. The engine stops when the two forecast sets do not align.

## Scoring

Demand and price are measured in different units, so each is min-max normalized within the current candidate set:

```text
normalized value = (value - minimum) / (maximum - minimum)
```

The opportunity score is:

```text
opportunity = 0.50 × normalized demand + 0.50 × normalized price
```

The weights are neutral because no verified client preference exists. They can later become configuration or an administrator setting.

Scores are relative, not probabilities. A score such as `0.57` does not mean 57% success; it means the candidate ranks at that relative position among the available crop/month combinations.

## Output

```text
artifacts/recommendation/recommendations.json
```

The output includes validated farmer input, remaining land, scoring method, limitations, ranked recommendations, forecast values, normalized scores, and human-readable explanations.

## Known limitations

- Individual forecast confidence is not yet estimated.
- Growth duration is not yet used to translate planting month into harvest month.
- Soil, irrigation, production cost, expected yield, and agronomic suitability are not included.
- `crop_defaults.csv` contains placeholders until reliable growth-duration values are verified.
- Recommendations should be labelled market opportunity, not guaranteed planting advice.

## Future API integration

When the software database and API are ready:

- Replace `sample_farmer_input.json` with the authenticated request body and farm record.
- Replace `sample_active_plantings.json` with active planting rows from the database.
- Keep demand and price forecasts behind the Python AI service.
- Return several ranked recommendations rather than only the first crop.
- Store the model versions and forecast generation timestamp with each result.

The engine can be developed and tested now; only its input adapters need to change during application integration.
